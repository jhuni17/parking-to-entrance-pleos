# 주차까지

Pleos 내비의 목적지와 차량 조건을 바탕으로 주차장을 추천하고, 선택한 주차장 입구로 안내하는 차량용 앱입니다.

## 실행 방법

1. 에뮬레이터를 시작하고 저장소 루트에서 `adb install "apk/최재훈_주차까지_release.apk"`를 실행합니다.
2. Pleos 기본 내비에서 코엑스로 안내를 시작하고 ‘주차까지’를 엽니다. 추천 카드에서 차량 높이와 입구 제한을 확인합니다. **총높이 보완**에 2,350mm를 적용하면 시연용 대안 A로 전환됩니다.
3. Pleos 기본 내비에서 잠실역 2호선으로 안내를 시작하고 앱을 열면 실시간 요금과 빈자리를 확인할 수 있습니다. 신천유수지에 **입구 안내**가 표시되면 선택한 뒤 **내비 안내**를 누릅니다.

## 테스트 환경 및 필요한 설정

Windows x64에서 Android Automotive API 34 기반 Pleos 에뮬레이터와 ADB를 사용했습니다. 앱을 열기 전에 기본 내비에서 목적지 안내를 시작합니다. 잠실역의 실시간 요금과 빈자리를 확인하려면 서울 열린데이터광장에 접속할 수 있는 네트워크가 필요합니다. 주차장 추천은 조회한 빈자리와 차량 조건에 따라 달라집니다.

## Pleos Connect 에뮬레이터 버전 및 화면 규격

Pleos Connect Emulator 2.1.0, 가로 2560 × 1440 px (16:9).
